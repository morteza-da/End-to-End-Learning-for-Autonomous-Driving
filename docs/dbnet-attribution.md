## Suggested dataset acknowledgment

> This research implementation uses the DBNet LiDAR-video driving dataset introduced by Chen et al. (CVPR 2018). DBNet's creators retain attribution for the original dataset and baseline resources. This implementation's model implementation and any newly generated experiments are independent and should not be attributed to the original dataset authors.

## Attribution locations

- Project README: add a short dataset acknowledgment and citation link.
- Dataset documentation and master archival manual: include complete citation.
- Notebooks using DBNet: include citation and dataset URL in the opening markdown cell.
- Papers, figures, presentations, and derived reports: cite Chen et al. (2018).
- If original DBNet code is copied/adapted, comply separately with its Apache-2.0 code license and document provenance.

## Data access and rights

The official GitHub README states **its code** is under Apache 2.0, and directs readers elsewhere for the **dataset copyright**. Do **not** infer that all original DBNet data are Apache-2.0-licensed. Confirm dataset terms from the rights holder before redistribution or publishing samples/checkpoints that may expose restricted content. Linking and citing the dataset do not by themselves grant redistribution rights.

**Evidence:** official DBNet repository README, sections *Citation* and *License*, accessed October 2026.
